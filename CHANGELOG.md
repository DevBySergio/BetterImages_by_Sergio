# Change Log

All notable changes to the "betterimages" extension are documented here.

## [1.4.0]

- Redesigned the sidebar with clearer image-specific and global tool sections.
- Added export presets for Thumbnail, Avatar, Hero, and Open Graph images.
- Added export savings feedback with before/after file size and saved percentage.
- Added quick copy snippets for Markdown, CSS background, plain HTML, imports, and component code.
- Improved export safety by generating unique output names instead of overwriting existing files.
- Added explicit resize fit modes: inside, contain, cover, and fill.
- Made Dummy Placeholder and Color Picker available without selecting an image first.
- Added stronger validation, sanitization, and unit tests for core image-tool behavior.
- Updated native packaging setup for target-specific VSIX builds.
- Replaced the extension icon with a higher-quality image-processing themed icon.
